УРОК 1 · ПУНКТИ 1–4 § 9

Як «прочитати» графік функції?

Графік — це не просто лінія. Він повідомляє, коли функція дорівнює нулю, де вона додатна чи від’ємна, а також як змінюється її значення.

🕵️‍♀️📊
1

Нулі функції

Означення

Нулем функції називають значення аргументу x, за якого значення функції дорівнює нулю.

f(x) = 0
ГОЛОВНЕ: щоб знайти нулі функції, потрібно розв’язати рівняння f(x) = 0.

Приклад

Знайдемо нулі функції h(x) = x² − 2x − 8.

x² − 2x − 8 = 0

(x − 4)(x + 2) = 0

x₁ = 4; x₂ = −2.

Нулі функції: −2 і 4.

Що виділено?

Жовті точки — місця, де графік перетинає вісь Ox.

Їхні абсциси x = −1 і x = 1 — нулі функції.

У цих точках f(x) = 0.

2

Перетин графіка з осями координат

З віссю Ox

На осі Ox ордината дорівнює нулю.

(x; 0), де f(x) = 0

Абсциси точок перетину з Ox — це нулі функції.

З віссю Oy

На осі Oy абсциса дорівнює нулю.

(0; f(0))

Щоб знайти точку перетину з Oy, обчисли f(0).

Приклад: h(x) = x² − 2x − 8

З Ox: нулі −2 і 4 → точки (−2; 0) та (4; 0).

З Oy: h(0) = −8 → точка (0; −8).

Ox: прирівнюємо функцію до нуля. Oy: підставляємо x = 0.
Що виділено?

Жовта точка на осі Ox — (−1; 0), де f(−1) = 0.

Блакитна точка на осі Oy — (0; 1), де f(0) = 1.

Для перетину з Ox розв’язуємо f(x) = 0; для Oy підставляємо x = 0.

3

Проміжки знакосталості

Функція додатна

f(x) > 0

Графік розташований вище осі Ox.

Функція від’ємна

f(x) < 0

Графік розташований нижче осі Ox.

ГОЛОВНЕ: нулі функції розділяють область визначення на проміжки. На кожному проміжку перевіряємо, вище чи нижче осі Ox лежить графік.
Як записувати проміжки знакосталості?
f(x) > 0 — об’єднання проміжків, де графік вище Ox;
f(x) < 0 — об’єднання проміжків, де графік нижче Ox.
Нулі функції не включаємо до цих проміжків.
Проміжки знакосталості на схемі

Додатна: (−3; −1) ∪ (1; 4].

Від’ємна: [−4; −3) ∪ (−1; 1).

У точках x = −3, −1, 1 функція дорівнює нулю, тому ці точки не входять до проміжків строгого знака.

4

Зростання та спадання функції

Зростаюча функція

Якщо x₁ < x₂, то f(x₁) < f(x₂).

↗ зліва направо

Спадна функція

Якщо x₁ < x₂, то f(x₁) > f(x₂).

↘ зліва направо
Як визначити?

Зелена частина: графік піднімається зліва направо — функція зростає.

Рожева частина: графік опускається — функція спадає.

Точку переходу позначено жовтим.

5

Схематичний приклад: читаємо графік

На схемі задано графік функції на проміжку [−4; 4]. Ключові точки ламаної:

(−4; −2), (−2; 0), (0; 1), (2; 2), (3; 0), (4; −2).

Властивості за графіком

  • D(f) = [−4; 4]
  • E(f) = [−2; 2]
  • Нулі: x = −2; x = 3
  • Перетин з Oy: (0; 1)
  • f(x) > 0 на (−2; 3)
  • f(x) < 0 на [−4; −2) ∪ (3; 4]
  • Зростає на [−4; 2]
  • Спадає на [2; 4]

Лінійна функція y = kx + l, k ≠ 0

Якщо k > 0

↗ функція зростає на ℝ

D(f) = ℝ; E(f) = ℝ.

Нуль: x = −lk

f(x) > 0, коли x > −lk.

f(x) < 0, коли x < −lk.

Якщо k < 0

↘ функція спадає на ℝ

D(f) = ℝ; E(f) = ℝ.

Нуль: x = −lk

f(x) > 0, коли x < −lk.

f(x) < 0, коли x > −lk.

2

Обернена пропорційність y = kx, k ≠ 0

Якщо k > 0

D(f) = ℝ \ {0}; E(f) = ℝ \ {0}.

Нулів немає.

f(x) > 0 при x > 0; f(x) < 0 при x < 0.

Спадає на (−∞; 0) і (0; +∞).

Якщо k < 0

D(f) = ℝ \ {0}; E(f) = ℝ \ {0}.

Нулів немає.

f(x) > 0 при x < 0; f(x) < 0 при x > 0.

Зростає на (−∞; 0) і (0; +∞).

3

Квадратична функція y = x²

D(f) = ℝ

E(f) = [0; +∞)

Єдиний нуль: x = 0.

f(x) > 0 при x ≠ 0; від’ємних значень не має.

Спадає на (−∞; 0] і зростає на [0; +∞).

Найменше значення — 0. Найбільшого немає.

Графік — парабола

4

Функція y = √x

D(f) = [0; +∞)

E(f) = [0; +∞)

Єдиний нуль: x = 0.

f(x) > 0 при x > 0; від’ємних значень не має.

Зростає на [0; +∞).

Найменше значення — 0. Найбільшого немає.

Графік починається в точці (0; 0)
